RECOMMENDED_RAG_BEHAVIOR:
1. Identify the college mentioned by the user.
2. Identify the information category requested.
3. Retrieve chunks whose COLLEGE and category match the query.
4. Prefer official university sources over secondary sources.
5. For time-sensitive information such as deadlines, tuition, requirements,
   and financial aid, retrieve current web content from the source URL when possible.
6. Return the source URL with the answer so the UI can expose a citation/link.
7. If multiple colleges are requested, retrieve comparable categories for each college.
8. Do not invent a value when the source does not provide it.
9. Distinguish between "source page available" and "fact extracted from source."
10. When the user asks to compare colleges, normalize the retrieved data into
    consistent fields so it can be displayed as a table.

SUGGESTED_TABLE_FIELDS:
- College
- Location
- Application / Admission
- Deadline
- Major / Program
- Tuition / Cost
- Financial Aid
- Research
- Internships / Careers
- Housing
- Dining
- Campus Life
- Student Life
- Source

NOTE:
This is a SOURCE-INDEX knowledge base, not a static database of admissions facts.
The URLs should be crawled/retrieved and re-indexed periodically so the chatbot
does not rely on stale admissions deadlines, tuition, requirements, or policies.
