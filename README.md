# College-Tracker-Project
----
This project is meant for students to research crucial information during the college application process and to simplify planning and decision-making in one singular place.

----

## Key Features

- An AI interface to model search queries and gather info regarding both University of California campus' and out of state colleges.

- Accessible UI and design interface meant for high school students to both research and organize crucial information.

- Any info the user wishes to note can be added to an organized table, filed under university name, location, tuition, etc and can be given separate notes.

----

## Tech Stack

- Frontend currently in progress, built using HTML/CSS and Flask

- Powered using Gemini to handle fast responses and structured outputs that can be organized in given headers.

- Data parsing handled with Regex and Requests
